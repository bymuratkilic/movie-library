## 🎬 Perde nedir?

**Perde**, film ve dizi koleksiyonunu kendi zevkine göre yönetebileceğin kişisel bir arşiv uygulamasıdır. İzlediklerini kaydedebilir, daha sonra izlemek istediklerini listene ekleyebilir, favorilerini ayırabilir ve yapımları kendi puanınla değerlendirebilirsin.

KINOZ'dan ilham alan sade arayüzü; açık ve koyu tema seçenekleri, mavi vurgu rengi ve duyarlı tasarımıyla masaüstü ve mobil ekranlarda rahat bir deneyim sunmayı hedefler.

## ✨ Öne çıkan özellikler

- **Kişisel kütüphane:** Film, dizi ve belgesel arşivini tek yerde düzenle.
- **İzleme listeleri:** İzlediklerini, izleme listendekileri ve favorilerini ayrı ayrı takip et.
- **Kişisel puanlama:** Yapımlara 10 üzerinden Perde Puanı ver; kendi arşiv ortalamanı gör.
- **Yapım karşılaştırma:** İki yapımı temel bilgileriyle yan yana incele.
- **Keşif alanları:** Editörün Seçtikleri ve Gizli Cevherler bölümlerinde yeni yapımlar keşfet.
- **Zengin yapım detayları:** Konu, oyuncular, ekip, fragman ve benzer yapımlar gibi bilgilere göz at.
- **İstatistikler:** Arşivini ve izleme alışkanlıklarını analiz ekranından takip et.
- **TMDB entegrasyonu:** Film ve dizi verilerini, görselleri ve ilgili içerikleri keşfet.
- **Tema seçenekleri:** Açık ve koyu görünüm arasında geçiş yap.
- **Duyarlı tasarım:** Telefon, tablet ve masaüstü ekranlarına uyum sağlar.
- **Tarayıcıda saklama:** Kişisel arşiv verileri bu tarayıcının LocalStorage alanında tutulur.

## 💻 Yerel ortamda çalıştırma

1. Depoyu bilgisayarına klonla:

   ```bash
   git clone https://github.com/bymuratkilic/movie-library.git
   ```

2. Proje klasörüne gir:

   ```bash
   cd movie-library
   ```

3. `index.html` dosyasını bir yerel geliştirme sunucusu üzerinden aç. Örneğin VS Code içindeki Live Server eklentisini kullanabilirsin.

> **TMDB notu:** Projeyi kendi hesabınla çatallayıp geliştireceksen TMDB API kullanımını kendi API anahtarınla yapılandırman gerekir. Tarayıcı tarafında kullanılan anahtarların gizli kabul edilemeyeceğini unutma; özel veya sunucu tarafında tutulması gereken anahtarları herkese açık JavaScript dosyalarına ekleme.

## 🌍 Yayınlama

Proje GitHub Pages üzerinde yayımlanır. Kendi kopyanı yayımlamak için GitHub deposunda **Settings → Pages** bölümüne girip yayın kaynağı olarak `main` dalını ve kök klasörü (`/root`) seçebilirsin. Değişiklikler GitHub Pages tarafından yayımlandıktan sonra sitene ait bağlantı üzerinden erişebilirsin.
